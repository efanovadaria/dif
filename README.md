# Задание текущего контроля по МДК.01.02 Поддержка и тестирование программных модулей

## Выполнила:
Ефанова Дарья группа 3ИСИП-523

## Вариант
Вариант 3 — Калькулятор чаевых

## Описание
WPF-приложение для расчета чаевых и разделения счета между гостями.

## Возможности
- Ввод суммы счета
- Выбор процента чаевых
- Разделение счета между гостями
- Обработка ошибок
- Автоматизированное тестирование
## Технологии
- C#
- WPF
- MSTest
